# Personal data is never shared across Workspaces

Public company data (Prospects, Signals, Detected Roles) is shared across Workspaces, because it holds no personal data and gets better with every customer.
Personal data (Candidates, Hiring Contacts, contact details) and each Workspace's own judgements (Skipped people, Claims, notes) stay inside the Workspace, which enriches for itself and keeps its own Provenance.
Pooling personal data across customers would make us a contact-data broker, the model the CNIL fined KASPR €240k for in December 2024.
The one exception is opt-outs, which are honoured across all Workspaces from a hashed Suppression List.
