# Contact data is kept only with verifiable Provenance

Every email or phone value we keep must carry Provenance that would satisfy a CNIL inspection and a data-access request: the provider or public page it came from, when, and how.
Providers that cannot give a source per value are excluded.
This is why Exa's Fiber contact reveals are never used (sourced from data brokers, a US-only service, no GDPR terms), and why an Exa value is kept only when Exa cites a public page that we re-fetch and find the value on.
Candidates are never contacted at their current employer's address, and mobile numbers are enriched only on an explicit Recruiter action, never automatically.
